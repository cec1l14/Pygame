## 🚀 Como Executar os Scripts

1. **Certifique-se de ter o Python instalado:**
   ```bash
   python --version

2. **Clone o repositório:**
   ```bash
   git clone https://github.com/cec1l14/Pygame.git
   
3. **Acesse a pasta do projeto:**
   ```bash
   cd Pygame
   
4. **Instale as dependências:**
   ```bash
   pip install pygame

5. **Execute:**
   ```bash
   python main.py
